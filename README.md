## Install Instructions

### 1. Clone the repository

```
git clone https://github.com/CalvinVolkmann0400/Git-Essentials.git
cd Git-Essentials
```

### 2. Create and activate a virtual environment

```
python -m venv .venv
```

* Windows: `.venv\Scripts\activate`
* macOS / Linux: `source .venv/bin/activate`

### 3. Install dependencies

```
pip install -r requirements.txt
```

### 4. Run the code

* Run a Python script: `python assignments/file-name.py`
* Launch a Streamlit app: `streamlit run projects/project-name/app.py`
