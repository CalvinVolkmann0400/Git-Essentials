## 📁 Directory Structure

```text
Git-Essentials/
├── README.md            # You are here
├── prep-work/           # Weekly prep assignments (prep-work-01, prep-work-02, ...)
├── assignments/         # Graded homework and in-class exercises
├── projects/            # Larger builds, e.g. Streamlit apps
│   └── <project-name>/
│       ├── app.py
│       └── README.md
├── data/                # Small sample datasets (CSV) used by the code
├── notes/               # Markdown notes and cheat sheets
├── requirements.txt     # Python dependencies
└── .gitignore           # Keeps venvs, caches, and secrets out of Git
```

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/CalvinVolkmann0400/Git-Essentials.git
cd Git-Essentials
```

**2. Create and activate a virtual environment**

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the code**

```bash
# Run a Python script
python assignments/<file-name>.py

# Launch a Streamlit app
streamlit run projects/<project-name>/app.py
```
